# Music Streaming Analytics System

## Overview
A MySQL-based Advanced Database Management System project that analyzes music streaming activity, listener engagement, song popularity, and genre preferences.

## Features
- Most-streamed songs analysis
- Listener activity leaderboard
- Popular music genre identification
- Daily streaming trend analysis
- Favorite genre detection using CTEs
- Listener-specific reports
- Playback duration validation

## Technologies Used
- MySQL 8.0
- MySQL Workbench
- SQL

## Advanced DBMS Concepts
- Joins and aggregations
- Views
- Stored procedures
- Triggers
- Indexing
- Common Table Expressions (CTEs)
- Window functions

## How to Run
1. Open MySQL Workbench and connect to your server.
2. Execute `music_streaming.sql` to create the database and insert sample data.
3. Execute `music_streaming_v2.sql` to add advanced database features.
4. Execute `music_demo.sql` to generate streaming analytics reports.

**Note:** Run setup scripts only once. The demo queries can be executed repeatedly.

## Result
The system successfully analyzes popular songs, listener activity, genre preferences, and daily streaming patterns.
